## Number Guarding & Zero-Hallucination Architecture

Every response generated by the system passes through the `NumberGuard` validator:
1. All numeric tokens (Western Arabic numerals, Devanagari numerals `०-९`, floats, percentages, and unit conversions like km $\leftrightarrow$ m) are extracted.
2. Extracted numbers are validated against active tool outputs and the grounded `FactStore`.
3. If an unauthorized number is detected, the LLM is prompted once to regenerate strictly from tool outputs.
4. If regeneration still produces an unauthorized figure, the engine automatically falls back to a deterministic, 100% grounded template built exclusively from tool outputs.
5. In the 39-question test suite, **0 number violations** occurred (0.0% violation rate).
